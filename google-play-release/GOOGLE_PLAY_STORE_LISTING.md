## 3. 隱私權政策 (Privacy Policy Template)

*（可將以下內容託管至 GitHub Pages 或靜態網頁，並填入 Google Play Console 欄位）*

```markdown
# Privacy Policy for Crew Story

Effective Date: 2026-09-05
Last Updated: 2026-09-05

Crew Story ("we", "our", or "the App") is developed by the Crew Pocket team as an open-source, privacy-focused application.

1. Information We Collect and How We Use It
- Local Storage: Story texts, page settings, and customized parameters are saved exclusively on the user's local device storage.
- API Key (BYOK): If the user enters a Google Gemini API Key, it is encrypted and stored locally on the device solely for communicating with Google Gemini API endpoints. We do not transmit or store API keys on any third-party server.
- Audio Recording: Microphone permissions are requested only if the user explicitly uses voice interaction features. Audio is streamed directly to the AI service and is never recorded or stored on our servers.
- Photos/Images: Image picking permissions are used solely to import user-selected illustrations for local storybooks.

2. Third-Party Services
The App interacts directly with:
- Google Gemini API (AI text, audio, and image generation) according to Google's Privacy Policy.

3. Children's Privacy
Crew Story does not collect any personally identifiable information from children or adults.

4. Contact Us
If you have any questions, please contact us at: support@crewpocket.dev
```
